## 🚀 Deployment & Hosting Guide

This repository is built with **zero external build dependencies** (pure semantic HTML5, modern CSS3, and vanilla ES6 JavaScript) and runs instantly on any static web server.

### Option 1: GitHub Pages (Root Hosting at `digitallykaran.github.io`)
1. Create a repository named `digitallykaran.github.io` on GitHub.
2. Upload all files from this folder directly into the **root** of the repository (ensure `index.html` is in the main directory).
3. In GitHub repo **Settings** &rarr; **Pages**, set **Source** to `Deploy from a branch` &rarr; `main` branch &rarr; `/ (root)` folder &rarr; **Save**.
4. The site is live at [https://digitallykaran.github.io/](https://digitallykaran.github.io/).

### Option 2: Netlify Drop (Instant 30-Second Live URL)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this folder directly into the browser window for an instant HTTPS URL.

### Option 3: Vercel Deployment
Deploy instantly via Vercel CLI or by importing the GitHub repository:
```bash
npx vercel
```
*(Pre-configured caching and security headers are handled via [`vercel.json`](vercel.json))*.
